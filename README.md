# ZerOS 8.0 searchable online manual

Static site reconstructed from the provided 343-page PDF. All PDF page text is searchable, and the original PDF is included for diagrams and original layout. This is an initial archival site, not a complete reconstruction of the original website's topic-level hyperlinks, embedded images, or console-specific filtering.

## Publish free with GitHub Pages
1. Create a public GitHub repository.
2. Upload the **contents** of this folder to the repository root.
3. In repository **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)`, then Save.
4. Open the URL shown by GitHub Pages after deployment.

## Local preview
From this directory run `python -m http.server 8000`, then visit `http://localhost:8000`. Do not open index.html directly from disk because the browser blocks fetch() for local files.
